# Jardín digital · Elver Chaparro

Notas en proceso sobre investigación cualitativa, estudios visuales y creación, publicadas desde Obsidian con [Quartz](https://quartz.jzhao.xyz/).

- Las notas viven en `content/`. Esa carpeta se abre en Obsidian como bóveda.
- `content/privado`, `content/borradores` y `content/plantillas` no se publican.
- Cada push a `main` construye y publica el sitio con GitHub Actions (`.github/workflows/deploy.yml`).

Vista local: `npx quartz build --serve`
